# Japanese Language

日本語でプログラミングできる、自作プログラミング言語です。

> 「プログラミングを、もっと直感的に。」

## 現在のバージョン

**v2.2.0**

Japanese Language v2.2.0では、PC版に加えてWeb版にも対応しています。また、URL版も公開しています。

v2.2.0では、エラー処理を強化し、エラーの行番号や原因をより分かりやすく表示できるようになりました。

### PC版

Pythonを実行基盤として使用しています。

```text
.jp ソースコード

      ↓

Japanese Language

      ↓

Pythonコードへ変換

      ↓

Pythonで実行
```

### Web版

Webブラウザ上で`.jp`ファイルを実行できます。

```text
.jp ソースコード

      ↓

Japanese Language Web

      ↓

JavaScriptエンジン

      ↓

ブラウザ上で実行
```

### URL版

以下を開くことによって、ネットがあればどこでも利用できます。

```text
https://sho36sho36.github.io/JapaneseLanguage/
```

PC版とWeb版で、同じ日本語プログラミング言語の構文を使用することを目指しています。

# 実際のコード

## 変数

変数には日本語の文章に近い感覚で値を入れられます。

```text
変数「名前」に入れる「自作言語」

変数「数字」に入れる 100

表示する「こんにちは！」

表示する 名前

表示する 数字
```

PC版では、おおよそ次のようなPythonコードへ変換されます。

```python
名前 = '自作言語'

数字 = 100

print('こんにちは！')

print(名前)

print(数字)
```

---

# 表示

`表示する`を使うことで文字列や変数などを表示できます。

```text
表示する「こんにちは！」

変数「名前」に入れる「自作言語」

表示する 名前
```

---

# 入力

`入力する`を使うことでユーザーから入力を受け取れます。

```text
入力する「名前」

表示する 名前
```

---

# 計算

計算結果を表示できます。

```text
計算する 10 + 20

計算する 100 * 2
```

例えば、

```text
変数「数字」に入れる 100

計算する 数字 * 2
```

とすると、`200`が表示されます。

---

# 条件分岐

`もし`、`それ以外`、`終わり`を使って条件分岐できます。

```text
変数「数字」に入れる 100

もし 数字 >= 100

    表示する「100以上です」

それ以外

    表示する「100未満です」

終わり
```

PC版では、おおよそ次のようなPythonコードへ変換されます。

```python
数字 = 100

if 数字 >= 100:

    print('100以上です')

else:

    print('100未満です')
```

---

# 繰り返し

指定した回数だけ処理を繰り返せます。

```text
繰り返す 5回

    表示する「繰り返しています」

終わり
```

この例では「繰り返しています」が5回表示されます。

---

# ループを抜ける

`抜ける`を使うことで、繰り返し処理を途中で終了できます。

```text
繰り返す 10回

    表示する「処理中」

    抜ける

終わり
```

---

# 待つ

指定した秒数だけ処理を待機できます。

```text
待つ 1

表示する「1秒待ちました！」
```

Web版ではブラウザ上で非同期に待機します。

# モジュール・パッケージ

v2.2.0では、`.jp`ファイルから別のモジュールを読み込めます。

また、GitHub上に公開されたパッケージを利用できます。

## モジュールの読み込み

PC版では、別の`.jp`ファイルを読み込めます。

```text
読み込む「packages/test-module/hello.jp」
```

例えば、読み込むファイルに、

```text
表示する「モジュールが読み込まれました」
```

と記述しておくと、メインプログラムから読み込んで実行できます。

---

## GitHubパッケージ

Web版では、GitHub上のパッケージを読み込むことができます。

```text
読み込む「sho36sho36/jp-test-package」
```

GitHubリポジトリには、次のような構成のパッケージを用意できます。

```text
jp-test-package/

├─ package.jpkg
└─ src/
   └─ main.jp
```

`main.jp`には、パッケージとして実行するJapanese Languageコードを記述します。

例えば、

```text
表示する「GitHubからパッケージを読み込みました！」
```

と記述できます。

---

# package.jpkg

パッケージには`package.jpkg`というマニフェストファイルを配置します。

```json
{
  "name": "jp-test-package",
  "version": "1.0.0",
  "description": "Japanese Language用パッケージ",
  "author": "sho36sho36",
  "main": "src/main.jp",
  "license": "MIT",
  "repository": "https://github.com/sho36sho36/jp-test-package"
}
```

主な項目：

| 項目 | 説明 |
| ----- | ----- |
| `name` | パッケージ名 |
| `version` | パッケージのバージョン |
| `description` | パッケージの説明 |
| `author` | 作者 |
| `main` | 実行する`.jp`ファイル |
| `license` | ライセンス |
| `repository` | GitHubリポジトリ |

```powershell
py -3.14 -m pc.package_cli install sho36sho36/jp-test-package
```

```powershell
py -3.14 -m pc.package_cli install https://github.com/sho36sho36/jp-test-package
```

```powershell
py -3.14 -m pc.package_cli remove jp-test-package
```

PC版でインストールされたパッケージは、ユーザーのJapanese Languageパッケージフォルダで管理されます。

# エラー処理

v2.2.0ではエラー処理を強化しました。

エラーが発生した場合、行番号や原因を表示します。

例えば、

```text
終わり
```

のように、対応するブロックがない`終わり`を記述すると、

```text
行番号: 1

エラー: 対応するブロックがありません。

原因: この「終わり」に対応する「もし」または「繰り返す」がありません。
```

のように表示されます。

また、

* 余分な`終わり`
* `もし`の閉じ忘れ
* `繰り返す`の閉じ忘れ
* `それ以外`の誤った使用
* 存在しない変数
* 数値として扱えない値
* 不明な命令

などのエラーを検出します。

PC版ではPython側のエラー処理を利用します。

Web版ではJavaScript側のエラー処理によって、実行結果欄にエラーを表示します。
