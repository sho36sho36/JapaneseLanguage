# Japanese Language 🇯🇵

日本語でプログラムを書ける、自作プログラミング言語です。

「プログラミングをもっと日本語で、もっと分かりやすく」を目標に開発しています。

---

## 🌐 Web版

ブラウザだけでJapanese Languageを実行できます。

**Web版：**

https://sho36sho36.github.io/JapaneseLanguage/

インストール不要で、スマートフォン・タブレット・PCから利用できます。

# 🚀 v2.2.0

v2.2.0では、VS Code拡張機能の入力支援を大幅に強化しました。

## 🔮 入力補完

プログラムを書いている途中でも、対応するコマンドを候補として表示します。

例えば、

```text
ひょう
```

と入力すると、

```text
表示する
```

が候補に表示されます。

---

## 🔤 ひらがな入力途中に対応

変換を確定していない状態に近い入力でも、入力途中の文字からコマンドを検索できます。

例：

```text
けい
```

↓

```text
計算する
```

```text
くりかえ
```

↓

```text
繰り返す
```

```text
にゅう
```

↓

```text
入力する
```

---

## 🈶 漢字入力にも対応

漢字で途中まで入力した場合も候補を表示します。

```text
表示
```

↓

```text
表示する
```

```text
計算
```

↓

```text
計算する
```

---

## ⌨️ Tab / Enterで確定

補完候補を選択してTabまたはEnterを押すことで、コマンドを入力できます。

さらに、入力内容によってはスニペットが展開されます。

例えば、

```text
表示する
```

を選択すると、

```text
表示する「表示内容」
```

のように入力できます。

# 💻 Windows版

## インストール

プロジェクトをダウンロードまたはGitで取得します。

```powershell
git clone https://github.com/sho36sho36/JapaneseLanguage.git
```

プロジェクトフォルダへ移動します。

```powershell
cd JapaneseLanguage
```

---

## 実行

`.jp`ファイルを作成します。

例：

```text
hello.jp
```

内容：

```jp
表示する「こんにちは！」
```

そして、

```powershell
jp hello.jp
```

で実行できます。

# 💻 VS Code拡張機能

`vscode-extension` フォルダにはJapanese Language用のVS Code拡張機能があります。

## 対応機能

* `.jp`ファイルの認識
* 日本語構文の色分け
* コマンド補完
* ひらがな途中入力による補完
* 漢字途中入力による補完
* スニペット
* Tab / Enterによる候補確定

---

## VSIXの作成

```powershell
cd vscode-extension
npm.cmd install
npx.cmd @vscode/vsce package
```

成功すると、

```text
japanese-language-2.2.0.vsix
```

が作成されます。

---

## VSIXのインストール

VS Codeで、

```text
Ctrl + Shift + P
```

を押します。

次に、

```text
Extensions: Install from VSIX...
```

を選択します。

そして、

```text
japanese-language-2.2.0.vsix
```

を選択してください。

# ⚠️ エラー処理

v2.1.0以降では、エラーを分かりやすく表示するようになりました。

例えば、対応するブロックがない`終わり`を書いた場合、

```text
行番号: 1
エラー: 対応するブロックがありません。
原因: この「終わり」に対応する「もし」または「繰り返す」がありません。
```

のように表示します。

## 対応しているエラー

* エラーの行番号表示
* エラー原因の日本語説明
* 構文エラー検出
* `終わり`の対応チェック
* `もし`の閉じ忘れ検出
* `繰り返す`の閉じ忘れ検出
* 存在しない変数の検出
* 数値として扱えない値の検出
