# Japanese Language

日本語でプログラミングできる、自作プログラミング言語です。

> 「プログラミングを、もっと直感的に。」

## 現在のバージョン

**v2.0.0**

Japanese Language v2.0.0では、PC版に加えてWeb版にも対応しています。

### PC版

Pythonを実行基盤として使用しています。

```text
.jp ソースコード
      ↓
Japanese Language
      ↓
Pythonコードへ変換
      ↓
Pythonで実行
```

### Web版

Webブラウザ上で`.jp`ファイルを実行できます。

```text
.jp ソースコード
      ↓
Japanese Language Web
      ↓
JavaScriptエンジン
      ↓
ブラウザ上で実行
```

PC版とWeb版で、同じ日本語プログラミング言語の構文を使用することを目指しています。

# 使い方

## PC版

プロジェクトフォルダで`.jp`ファイルを指定します。

```powershell
jp programs\hello.jp
```

または、

```powershell
py -3.14 -m pc.jp programs\hello.jp
```

プロジェクトに含まれている`jp.bat`を利用することもできます。

# Web版

`web/index.html`をブラウザで開くことでWeb版を使用できます。

Web版では、エディタにJapanese Languageのコードを入力して、そのまま実行できます。

```text
コード
   ↓
▶ 実行
   ↓
実行結果
```

Web版はビルド済みの`web/app.js`を使用します。

Web版のソースを変更した場合は、次のコマンドで再ビルドできます。

```powershell
cd web
.\build-web.cmd
```

# 実際のコード

## 変数

変数には日本語の文章に近い感覚で値を入れられます。

```text
変数「名前」に入れる「自作言語」

変数「数字」に入れる 100

表示する「こんにちは！」

表示する 名前

表示する 数字
```

PC版では、おおよそ次のようなPythonコードへ変換されます。

```python
名前 = '自作言語'
数字 = 100

print('こんにちは！')
print(名前)
print(数字)
```

---

# 表示

`表示する`を使うことで文字列や変数などを表示できます。

```text
表示する「こんにちは！」

変数「名前」に入れる「自作言語」

表示する 名前
```

---

# 入力

`入力する`を使うことでユーザーから入力を受け取れます。

```text
入力する「名前」

表示する 名前
```

---

# 計算

計算結果を表示できます。

```text
計算する 10 + 20

計算する 100 * 2
```

例えば、

```text
変数「数字」に入れる 100

計算する 数字 * 2
```

とすると、`200`が表示されます。

---

# 条件分岐

`もし`、`それ以外`、`終わり`を使って条件分岐できます。

```text
変数「数字」に入れる 100

もし 数字 >= 100
    表示する「100以上です」
それ以外
    表示する「100未満です」
終わり
```

PC版では、おおよそ次のようなPythonコードへ変換されます。

```python
数字 = 100

if 数字 >= 100:
    print('100以上です')
else:
    print('100未満です')
```

---

# 繰り返し

指定した回数だけ処理を繰り返せます。

```text
繰り返す 5回
    表示する「繰り返しています」
終わり
```

この例では「繰り返しています」が5回表示されます。

---

# ループを抜ける

`抜ける`を使うことで、繰り返し処理を途中で終了できます。

```text
繰り返す 10回
    表示する「処理中」
    抜ける
終わり
```

---

# 待つ

指定した秒数だけ処理を待機できます。

```text
待つ 1

表示する「1秒待ちました！」
```

Web版ではブラウザ上で非同期に待機します。

---

# 変数の増減

変数の値を増やしたり減らしたりできます。

```text
変数「数字」に入れる 100

増やす 数字 50

表示する 数字

減らす 数字 20

表示する 数字
```

実行すると、

```text
150
130
```

のようになります。

```text
表示する 数字

割る 数字 5

表示する 数字

余り 数字 7

表示する 数字
```

# リスト

リストを作成して、値を追加したり取り出したりできます。

## リストを作る

```text
リスト「果物」を作る
```

## リストに追加する

```text
リスト「果物」に「りんご」を追加する

リスト「果物」に「バナナ」を追加する

リスト「果物」に「みかん」を追加する
```

## リストから削除する

```text
リスト「果物」から「バナナ」を削除する
```

## リストから取り出す

```text
リスト「果物」から取り出す 0
```

`0`は最初の要素を表します。

## リストの長さ

```text
リスト「果物」の長さ
```

例えば、

```text
リスト「果物」を作る

リスト「果物」に「りんご」を追加する
リスト「果物」に「バナナ」を追加する
リスト「果物」に「みかん」を追加する

リスト「果物」から取り出す 0

リスト「果物」の長さ
```

とすると、

```text
りんご
3
```

のような結果になります。

# PC版とWeb版

Japanese Language v2.0.0では、PC版とWeb版の2つの実行環境があります。

## PC版

PC版ではPythonを実行基盤として使用します。

```text
program.jp
    ↓
Japanese Language
    ↓
Pythonコード
    ↓
実行
```

## Web版

Web版ではJavaScriptによるエンジンを使用します。

```text
program.jp
    ↓
Japanese Language Web
    ↓
JavaScriptエンジン
    ↓
ブラウザで実行
```

両方とも、日本語による同じ`.jp`ソースコードを基本として使用します。

# プラグインシステム

Japanese Languageでは、機能をプラグインとして分離しています。

## PC版

```text
pc/
├─ engine.py
├─ jp.py
└─ plugins/
    ├─ display.py
    ├─ variable.py
    ├─ input.py
    ├─ calculate.py
    ├─ wait.py
    ├─ if_plugin.py
    ├─ else_plugin.py
    ├─ end.py
    ├─ repeat.py
    ├─ break_plugin.py
    └─ ...
```

## Web版

```text
web/
├─ engine/
│   ├─ engine.js
│   ├─ parser.js
│   ├─ plugin.js
│   └─ runtime.js
│
└─ plugins/
    ├─ display.js
    ├─ variable.js
    ├─ input.js
    ├─ calculate.js
    ├─ wait.js
    ├─ if.js
    ├─ else.js
    ├─ end.js
    ├─ repeat.js
    ├─ break.js
    └─ ...
```

新しい機能をプラグインとして追加することで、言語本体を大きく変更せずに機能を拡張できます。

# Web版のビルド

Web版では、開発用のソースコードを`app.js`にまとめています。

```text
web/
├─ main.js
├─ engine/
├─ plugins/
└─ app.js
```

ビルドにはesbuildを使用しています。

```powershell
cd web
.\build-web.cmd
```

ビルドが成功すると、

```text
web\app.js
```

が生成・更新されます。

# VSCode拡張機能

`vscode-extension`フォルダには、`.jp`ファイル用のVSCode拡張機能が含まれています。

v2.0.0のVSIXファイル：

```text
vscode-extension/
└─ japanese-language-2.0.0.vsix
```

## インストール方法

VSCodeを開き、

```text
Ctrl + Shift + P
```

を押します。

次に、

```text
Extensions: Install from VSIX...
```

を選択します。

その後、

```text
japanese-language-2.0.0.vsix
```

を指定してください。

これにより`.jp`ファイルでシンタックスハイライトを使用できます。
