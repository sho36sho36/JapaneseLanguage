# Japanese Language

日本語でプログラミングできる、自作プログラミング言語です。

> 「プログラミングを、もっと直感的に。」

## 現在のバージョン

**v1.5.1**

現在はPythonを実行基盤として使用しています。

```text
.jp ソースコード
      ↓
Japanese Language
      ↓
Pythonコードへ変換
      ↓
Pythonで実行
```

# 特徴

# 実際のコード

## 変数

変数には日本語の文章に近い感覚で値を入れられます。

```text
変数「名前」に入れる「自作言語」
変数「数字」に入れる 100

表示する「こんにちは！」
表示する 名前
表示する 数字
```

Pythonでは、おおよそ次のように変換されます。

```python
名前 = '自作言語'
数字 = 100

print('こんにちは！')
print(名前)
print(数字)
```

---

## 計算

計算結果を表示できます。

```text
計算する 10 + 20
計算する 数字 * 2
```

例えば、

```text
変数「数字」に入れる 100

計算する 数字 * 2
```

とすると、`200` が表示されます。

---

## 条件分岐

`もし`、`それ以外`、`終わり`を使って条件分岐できます。

```text
変数「数字」に入れる 100

もし 数字 >= 100
    表示する「100以上です」
それ以外
    表示する「100未満です」
終わり
```

Pythonでは、おおよそ次のように変換されます。

```python
数字 = 100

if 数字 >= 100:
    print('100以上です')
else:
    print('100未満です')
```

---

## 繰り返し

指定した回数だけ処理を繰り返せます。

```text
繰り返す 5回
    表示する「繰り返しています」
終わり
```

この例では「繰り返しています」が5回表示されます。

---

## 待つ

指定した秒数だけ処理を待機できます。

```text
待つ 1

表示する「1秒待ちました！」
```

---

## 変数の増減

変数の値を増やしたり減らしたりできます。

```text
変数「数字」に入れる 100

増やす 数字 50
表示する 数字

減らす 数字 20
表示する 数字
```

実行すると、

```text
150
130
```

のようになります。

---

## 掛ける・割る・余り

数値に対する基本的な操作にも対応しています。

```text
変数「数字」に入れる 100

掛ける 数字 2
表示する 数字

割る 数字 5
表示する 数字

余り 数字 7
表示する 数字
```

---

# リスト

リストを作成して、値を追加したり取り出したりできます。

## リストを作る

```text
リスト「果物」を作る
```

---

## リストに追加する

```text
リスト「果物」に「りんご」を追加する
リスト「果物」に「バナナ」を追加する
リスト「果物」に「みかん」を追加する
```

---

## リストから取り出す

```text
リスト「果物」から取り出す 0
```

`0`は最初の要素を表します。

---

## リストの長さ

```text
リスト「果物」の長さ
```

例えば、

```text
リスト「果物」を作る
リスト「果物」に「りんご」を追加する
リスト「果物」に「バナナ」を追加する
リスト「果物」に「みかん」を追加する

リスト「果物」から取り出す 0
リスト「果物」の長さ
```

とすると、リストの最初の要素や要素数を取得できます。

---

# 数値操作

## 最大値

```text
最大 10, 50, 20
```

結果：

```text
50
```

---

## 最小値

```text
最小 10, 50, 20
```

結果：

```text
10
```

---

## 絶対値

```text
絶対値 -100
```

結果：

```text
100
```

---

## 四捨五入

```text
四捨五入 3.6
```

結果：

```text
4
```

# VSCode拡張機能

`vscode-extension` フォルダには、`.jp` ファイル用のVSCode拡張機能が含まれています。

VSIXファイル：

```text
vscode-extension/
└─ japanese-language-0.1.0.vsix
```

## インストール方法

VSCodeを開き、

```text
Ctrl + Shift + P
```

を押します。

次に、

```text
Extensions: Install from VSIX...
```

を選択します。

その後、

```text
japanese-language-0.1.0.vsix
```

を指定してください。

これにより `.jp` ファイルでシンタックスハイライトを使用できます。

# プラグインシステム

この言語では、機能をプラグインとして分離しています。

```text
plugins/
├─ display.py
├─ variable.py
├─ input.py
├─ calculate.py
├─ wait.py
├─ if_plugin.py
├─ else_plugin.py
├─ end.py
├─ repeat.py
├─ break_plugin.py
└─ ...
```

新しい機能をプラグインとして追加することで、言語本体を大きく変更せずに機能を拡張できます。
