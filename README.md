# Japanese Language

日本語でプログラミングできる、自作プログラミング言語です。

> 「プログラミングを、もっと直感的に。」

## 現在のバージョン

**v1.4.0**

現在はPythonを実行基盤として使用しています。

~~~text
.jp ソースコード
      ↓
Japanese Language
      ↓
Pythonコードへ変換
      ↓
Pythonで実行
~~~

---

## 特徴

- 🇯🇵 日本語でプログラミング
- 🧩 プラグイン方式で機能を追加
- 🐍 Pythonを実行基盤として利用
- 💻 Windowsで実行可能
- 🎨 VSCode用シンタックスハイライト対応
- 🔢 数値計算に対応
- 🔀 条件分岐に対応
- 🔁 繰り返しに対応
- 📋 リストに対応
- 🔤 文字列操作に対応

# インストール

## 必要なもの

- Windows
- Python 3.10以上推奨

Pythonがインストールされていることを確認します。

~~~powershell
py --version
~~~

---

## ダウンロード

GitHubの **Code → Download ZIP** からダウンロードできます。

またはGitを使う場合：

~~~powershell
git clone https://github.com/sho36sho36/JapaneseLanguage.git
~~~

---

# 使い方

プロジェクトフォルダで `.jp` ファイルを指定します。

~~~powershell
jp programs\hello.jp
~~~

または、

~~~powershell
py jp.py programs\hello.jp
~~~

# サンプル

## 「こんにちは」と表示する

~~~text
表示する「こんにちは！」
~~~

Pythonでは、おおよそ次のように変換されます。

~~~python
print('こんにちは！')
~~~

---

## 変数

~~~text
名前 = 「自作言語」
数字 = 100

表示する 名前
表示する 数字
~~~

---

## 計算

~~~text
表示する 10 + 20
表示する 100 * 2
~~~

---

## 条件分岐

~~~text
数字 = 100

もし 数字 >= 100
    表示する「100以上です」
それ以外
    表示する「100未満です」
終わり
~~~

---

## 繰り返し

~~~text
繰り返す 5回
    表示する「繰り返しています」
終わり
~~~

---

## 変数の増減

~~~text
数字 = 100

増やす 数字 50
表示する 数字

減らす 数字 20
表示する 数字
~~~

---

## リスト

~~~text

追加する 果物 「バナナ」
追加する 果物 「みかん」

表示する 取り出す 果物 0
表示する 長さ 果物
~~~

# VSCode拡張機能

`vscode-extension` フォルダには、`.jp` ファイル用のVSCode拡張機能が含まれています。

VSIXファイル：

~~~text
vscode-extension/
└─ japanese-language-0.1.0.vsix
~~~

## インストール方法

VSCodeを開き、

~~~text
Ctrl + Shift + P
~~~

を押します。

次に、

~~~text
Extensions: Install from VSIX...
~~~

を選択します。

その後、

~~~text
japanese-language-0.1.0.vsix
~~~

を指定してください。

これにより `.jp` ファイルでシンタックスハイライトを使用できます。

# プラグインシステム

この言語では、機能をプラグインとして分離しています。

~~~text
plugins/
├─ display.py
├─ variable.py
├─ input.py
├─ calculate.py
├─ wait.py
├─ if_plugin.py
├─ else_plugin.py
├─ end.py
├─ repeat.py
├─ break_plugin.py
└─ ...
~~~

新しい機能をプラグインとして追加することで、言語本体を大きく変更せずに機能を拡張できます。
